   拉取发布镜像并验证部署            failure（第 8 步「冒烟验证」）

   失败原因：验证部署阶段用 docker run 启动后端容器时未设置 --network-alias backend。
   compose 编排里 backend 是服务名，会自动成为容器网络内的 DNS 别名；docker run 只有容器名
   campushub-backend，没有 backend 别名，于是 Nginx 启动时解析 proxy_pass 的 upstream 失败：

     2026/10/21 07:03:48 [emerg] 1#1: host not found in upstream "backend"
       in /etc/nginx/conf.d/default.conf:15

   Nginx 进程退出 → 8080 无监听 → 冒烟 curl 连不上 → 该步骤失败。

   修复：后端容器补充 --network-alias backend（与 compose 服务名语义一致）。
   本地同构验证：创建测试网络，用带别名的占位容器 + campushub-frontend:local 起 Nginx，
   日志无 [emerg]、容器 healthy、GET / 返回 200。
