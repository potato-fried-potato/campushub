### 三、跨模块协作与验收规则

1. **契约先行**：模块间依赖的接口字段与状态码必须先更新 `docs/02` API 契约，再进入编码；受影响单元的前后端主责人在站会同步；
2. **共用底座**：前端工程骨架与统一请求封装（蒲承玺牵头）、后端工程骨架与统一响应/异常规范（李俊宁牵头）作为横向底座先行提供，各模块按契约接入；
3. **模块完成定义 (DoD)**：`docs/06` 中对应模块的测试用例全部通过 + 相关文档更新，二者缺一不可；
4. **模块验收**：模块交付后，由边皓东对照 `docs/01` 的 AC 组织验收、伍宇轩按 `docs/06` 执行回归用例验证，通过后在看板将卡片移入 Done；
5. **推荐交付顺序**：M1 用户模块 → M2 商品模块 → M3 交易与互动模块 → M4 平台门户模块 → M5 信用与治理模块 → M6 工程交付线收口；认证与商品主链路先行，各迭代末随时可演示。
