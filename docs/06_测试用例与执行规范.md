### 四、执行与留档规范

1. **执行时机**：功能分支合并前，执行受影响模块的接口用例断言组；迭代末在 release 分支执行本迭代模块的全量用例；交付演示前执行 M6 脚本类用例与全量回归；
2. **留档方式**：接口类留存 `tests/api-e2e.ps1` 输出日志；UI 类留存操作截图与回归记录；脚本类留存命令输出与启动日志；
3. **通过标准**：本迭代模块用例全部通过；失败用例登记后修复并重跑，重跑全绿方可关闭；
4. **可追溯性**：每条用例通过「关联 AC」列回溯验收标准；AC 或接口契约变更时，先更新 `docs/01` / `docs/02`，再同步本文件用例。
