## 一、项目说明

Sprint 1~3 共 12 个用户故事 / 52 故事点，按业务域划分为：用户模块（认证）、商品模块（发布 / 检索 / 详情 / 管理）、交易与互动模块（砍价 / 留言互动 / 意向预约）、平台门户模块（首页数据看板）、信用与治理模块（评价举报 / 管理后台）与工程交付线（一键启动脚本）。

已实现的主要能力：

- 学号注册与登录，密码 BCrypt 单向哈希存储，注册自动生成内联 SVG 头像；
- 集市商品列表：关键词 / 分类 / 成色 / 校区筛选，四种排序，分页，登录态自动排除自己发布的商品；
- 商品详情：多图切换、立省金额、卖家名片与联系方式复制、浏览量累加；
- 我的发布：状态筛选、下架 / 重新上架 / 标记已售，含越权与非法流转校验；
- 分类在售数量、平台统计（在售 / 成交 / 认证用户 / 累计浏览）接口。

需求、接口契约、数据模型、协作规范与测试设计均已完成文档化，见下节索引。

## 四、本地运行

### 1. 环境要求

- JDK 21
- Maven 3.9+
- Node.js 20+
- MySQL 8.0（默认 `localhost:3306`）

### 2. 初始化数据库

在项目根目录执行（会重建 `campushub` 库并导入演示数据）：

```bash
mysql -uroot -p --default-character-set=utf8mb4 -e "source db/init.sql"
```

脚本内置 14 个用户（含管理员 `admin`）、6 个分类、32 个商品、45 张商品图片与 5 条砍价记录。

### 3. 启动后端

```bash
cd backend
mvn spring-boot:run
```

后端默认运行在 `http://localhost:8080`。数据库账号密码在 `backend/src/main/resources/application.yml` 中，按本机 MySQL 配置修改即可。

### 4. 启动前端

```bash
cd frontend
npm install
npm run dev
```

前端运行在 `http://localhost:5173`，Vite 已把 `/api` 代理到后端 8080 端口。

## 五、已实现接口

| 方法 | 路径 | 说明 |
| :---: | :--- | :--- |
| POST | `/api/auth/register` | 学号注册（自动登录并生成头像） |
| POST | `/api/auth/login` | 学号登录 |
| GET | `/api/items` | 集市列表（筛选 / 排序 / 分页） |
| GET | `/api/items/{id}` | 商品详情（浏览量 +1） |
| GET | `/api/items/mine` | 我的发布（状态筛选 / 分页） |
| PATCH | `/api/items/{id}/status` | 商品状态流转（在售 / 下架 / 已售） |
| GET | `/api/categories` | 分类列表与在售数量 |
| GET | `/api/system/stats` | 平台统计 |
| POST | `/api/files/upload` | 图片上传（文件头魔数校验，返回 Data URI） |
| POST | `/api/items` | 发布商品 |
| POST / GET | `/api/bargains` | 提交出价 / 砍价列表（收到 / 发出） |
| POST | `/api/bargains/{id}/accept\|reject\|cancel` | 接受 / 拒绝 / 取消出价 |
| POST / GET | `/api/reservations` | 提交预约 / 预约列表 |
| POST | `/api/reservations/{id}/confirm\|reject\|cancel` | 确认 / 拒绝 / 取消预约 |
| POST / GET | `/api/items/{itemId}/messages` | 发表留言与回复 / 商品留言列表 |
| GET / PATCH | `/api/messages/mine`、`/api/messages/{id}/read` | 我的留言（收到 / 发出）/ 标记已读 |
| POST | `/api/reviews`、`/api/reports` | 提交评价 / 提交举报 |
| GET | `/api/users/{userId}/reviews` | 用户信用与评价列表 |
| GET / PATCH | `/api/admin/**` | 管理后台（用户 / 商品 / 举报处置） |

完整请求参数、响应结构与业务码见 [02. RESTful API 接口契约](docs/02_RESTful_API接口契约.md)。除匿名接口外均需在请求头携带 `Authorization: Bearer <token>`，前端已统一注入；未登录访问受保护接口返回 HTTP 401。

## 六、一键脚本与回归

- `一键启动.bat`：六步自检（JDK 21 → MySQL80 服务 → 数据库结构与自动导入 → 前端产物构建 → 后端打包 → 启动并打开浏览器）；
- `一键停止.bat`：释放 8080 端口并关闭后端进程；
- `db\init-db.bat`：一键重建演示数据（14 用户 / 6 分类 / 32 商品 / 45 图 / 5 条砍价）；
- `tests\api-e2e.ps1`：接口 E2E 回归，覆盖认证、鉴权、检索、详情、留言、砍价、预约、评价举报与管理后台的关键断言。
