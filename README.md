# 智校互联 (CampusHub) 校园二手交易协同平台

> **《软件工程项目实现》课程设计 · 软件工程 2402 · 第 11 组**  
> **技术栈**：Spring Boot 3 + Vue 3 (Vite 工程化) + MySQL 8.0（零外部中间件开箱即用体系，技术决策见 `docs/01`）  
> **当前状态**：开发进行中——需求与规范文档、前后端工程骨架、数据库脚本均已就位；Sprint 1 已向 `develop` 合并登录、商品列表、我的发布 3 条纵切，其余功能与测试待开发，进度见 `docs/05` 第四节

---

## 一、项目说明

Sprint 1~3 共 12 个用户故事 / 52 故事点，按业务域划分为：用户模块（认证）、商品模块（发布 / 检索 / 详情 / 管理）、交易与互动模块（砍价 / 留言互动 / 意向预约）、平台门户模块（首页数据看板）、信用与治理模块（评价举报 / 管理后台）与工程交付线（一键启动脚本）。

需求、接口契约、数据模型、协作规范与测试设计均已完成文档化，见下节索引。

---

## 二、团队

本项目由软件工程 2402 第 11 组 6 人团队承接，分工采用**功能模块 × 前后端协作**模式：每个交付单元由前端、后端各 1 名主责人共同完成；成员名单与分工表见 [05. 团队组织与功能模块分工](docs/05_团队组织与功能模块分工.md)。
